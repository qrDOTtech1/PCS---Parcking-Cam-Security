Chapitre 1
01

Du code source à Internet

Récupérer PCS & le déployer sur Railway

Alors. Vous voulez déployer un système de surveillance digne de ce nom. Bien. Parce que laisser votre parking sans surveillance, c'est une invitation ouverte à tout ce que la société produit de moins reluisant. Commençons par le commencement — récupérer le code.

1

Trouver le dépôt de code

Rendez-vous sur GitHub. Cherchez simplement PCSPARKINGCAMERAV1 dans la barre de recherche. C'est le seul résultat qui compte. Cliquez dessus. Regardez le dépôt. Admirez-le une seconde. Puis forkez-le sur votre propre compte — vous en aurez besoin pour la suite.

Note : Un "fork" crée votre propre copie du projet. Railway en aura besoin pour déployer depuis votre dépôt. Pas de panique — c'est un bouton vert, vous ne pouvez pas le rater.
2

Créer un compte Railway

Rendez-vous sur railway.app et créez un compte. Maintenant, voici la partie que personne n'aime entendre : vous aurez besoin d'un plan payant. Le plan gratuit de Railway a des limitations qui rendront PCS aussi réactif qu'un fonctionnaire un vendredi après-midi. Souscrivez au moins au plan Hobby (~5$/mois). Pour ce que ça fait, c'est le meilleur investissement que vous ferez cette année.

⚠ Important : Sans plan payant, votre instance PCS s'endormira et manquera des détections critiques. Ce n'est pas une suggestion — c'est un fait.
3

Déployer depuis GitHub

Dans Railway : New Project → Deploy from GitHub repo. Sélectionnez votre fork de PCSPARKINGCAMERAV1. Railway va détecte automatiquement le Procfile et construire l'image. Laissez-le faire. Ne touchez à rien. Il sait ce qu'il fait.

4

Configurer les variables d'environnement

Dans votre service Railway, allez dans l'onglet Variables. Ajoutez les variables suivantes. Sans elles, PCS tournera, mais comme un moteur sans huile — brièvement, puis dramatiquement.

SECRET_KEY = une-longue-chaine-aleatoire-ultra-secrete MASTER_KEY = votre-cle-administrateur-pcs DATABASE_URL = (ajoutée automatiquement si vous liez un plugin SQLite/Postgres) FLASK_SECRET_KEY = une-autre-chaine-aleatoire-differente
Astuce : Ajoutez un plugin Railway Volume pour la persistance du fichier SQLite. Sans ça, vos données disparaîtront à chaque redéploiement. Ce serait tragique.
5

Générer un domaine et vérifier

Onglet Settings → Domains → Generate Domain. Railway vous donne une URL en .railway.app. Cliquez dessus. Si vous voyez la page de connexion PCS, félicitations — vous venez de déployer un système de surveillance professionnel en moins de dix minutes. Prenez un moment pour apprécier votre propre efficacité.

Chapitre 2
02

L'outil administrateur

Créer des comptes & gérer les abonnements

Vous êtes maintenant, techniquement parlant, le maître absolu de votre instance PCS. Un grand pouvoir implique une grande responsabilité. Ou du moins, un mot de passe solide. L'Admin Tool est l'endroit où vous créez les comptes utilisateurs et définissez ce qu'ils ont le droit de faire.

1

Accéder au panneau admin

Naviguez vers /admin sur votre instance. Entrez votre MASTER_KEY — celle que vous avez définie dans les variables Railway. Vous voilà dans le saint des saints. Ne faites pas n'importe quoi.

2

Créer un compte utilisateur

Section "Créer un utilisateur" — remplissez le nom d'utilisateur et le mot de passe. Maintenant vient la partie intéressante : choisissez un mode d'abonnement.

Standard

3 caméras max, détection de base, notifications. Parfait pour débuter.

Emergency

Règles avancées type/couleur, priorités d'alerte, filtres fins.

Enterprise

Tout illimité. Caméras, règles, modèles IA, notifications. Le nec plus ultra.

3

Gérer les utilisateurs existants

Le tableau de bord admin liste tous les comptes. Vous pouvez modifier le nombre max de caméras, changer l'abonnement, ajouter des notes internes, ou supprimer un compte si quelqu'un a eu l'audace d'utiliser "12345" comme mot de passe malgré vos avertissements répétés. Le bouton rouge est là pour ça.

⚠ Ne perdez jamais votre MASTER_KEY Sans elle, vous ne pouvez plus accéder au panneau admin. Il n'y a pas de "mot de passe oublié" pour le Bon Dieu de l'instance. Vous devrez redéployer depuis zéro. Ce sera pénible. Notez-la quelque part de sûr.
Chapitre 3
03

Intelligence Artificielle

Roboflow — Clé API & modèles de détection

La détection YOLO intégrée est déjà remarquable. Mais si vous voulez que PCS reconnaisse des choses spécifiques — disons, un modèle particulier de véhicule, une tenue suspecte, ou n'importe quelle autre classe visuelle que vous imaginez — alors Roboflow est votre meilleur ami. Un ami qui vous demandera une clé API, mais un ami quand même.

1

Créer un compte Roboflow

Rendez-vous sur roboflow.com et créez un compte. Gratuit pour commencer — vous aurez accès aux modèles publics de l'univers, ce qui représente une quantité absurde d'intelligence artificielle pré-entraînée. C'est franchement indécent comme générosité.

2

Récupérer votre clé API

Dans votre compte Roboflow, allez dans Settings → Roboflow API. Vous y trouverez votre clé API privée. Copiez-la. C'est une longue suite de caractères apparemment aléatoires. Elle l'est. C'est votre sésame vers les cerveaux électroniques de Roboflow.

⚠ Ne partagez jamais votre clé API — c'est votre quota de calcul. Si quelqu'un d'autre l'utilise, vous payez la facture.
3

Trouver des modèles pertinents

Sur Roboflow, allez dans l'onglet Universe — c'est la bibliothèque publique. Cherchez ce dont vous avez besoin : "license plate", "person detection", "suspicious behavior"... Les possibilités sont quasiment infinies.

Sur la page d'un modèle, notez l'endpoint — il ressemble à ceci :

nom-du-modele/version // ex : police-detector/1

C'est ce que vous saisirez dans PCS. Notez-le.

4

Ajouter le modèle dans PCS

Dans votre tableau de bord PCS, section Modèles IA (Roboflow) — cliquez sur le formulaire d'ajout. Renseignez un nom descriptif, l'endpoint du modèle et votre clé API. Choisissez ensuite le comportement d'alerte :

Log only

Enregistre les détections silencieusement. Aucune alerte. Parfait pour tester ou observer.

Alerte tout

Alerte à chaque détection du modèle. Pour les cas où vous voulez être notifié de tout ce que l'IA voit.

Par classes

N'alerte que sur certaines classes du modèle. Le bouton "Récupérer classes" les charge automatiquement.

💡 Renforcement OCR Si vous avez un modèle Roboflow configuré, activez le Renforcement OCR dans la section dédiée. PCS utilisera Roboflow pour localiser précisément les plaques dans l'image avant de les lire — la précision de reconnaissance s'en trouve considérablement améliorée. C'est la différence entre lire un panneau de route à 130 km/h et à l'arrêt.
Chapitre 4
04

La PCS Cam v1

Configuration de la caméra dédiée PCS

La PCS Cam v1 est une pièce d'ingénierie embarquée sérieuse. Un module caméra WiFi compact, conçu spécifiquement pour PCS — streaming en direct, enregistrement de segments vidéo, détection temps réel, réponse aux commandes à la milliseconde. Ce n'est pas un gadget à 3 euros trouvé dans un bac à soldats. C'est un outil de surveillance professionnel, pensé, assemblé et calibré pour durer. Traitez-la en conséquence. Voici comment la mettre en service.

1

Flasher le firmware

La PCS Cam v1 est livrée — ou se programme — avec un firmware spécifique PCS. Utilisez l'outil de flashage fourni avec le module (via USB). Le processus prend environ 30 secondes. Si ça prend plus longtemps, quelque chose s'est mal passé. Recommencez.

2

Ajouter la caméra dans PCS

Dans votre tableau de bord PCS, cliquez sur Ajouter une caméra. Donnez-lui un nom évocateur — "Entrée Parking", "Sortie Nord", peu importe, mais pas "caméra1" s'il vous plaît, vous méritez mieux que ça. Définissez une clé API unique pour ce capteur — c'est son identité sur votre réseau PCS.

Nom : Entrée Parking Nord Clé API : pcscam-entree-nord-2024 // inventez quelque chose de mémorable
3

Configurer le WiFi de la caméra

Au premier démarrage, la PCS Cam v1 crée son propre point d'accès WiFi temporaire. Connectez-vous à ce réseau depuis votre téléphone ou PC — vous trouverez une interface de configuration à l'adresse 192.168.4.1. Renseignez :

SSID WiFi : votre-réseau-local Mot de passe : votre-mot-de-passe-wifi PCS Server : https://votre-instance.railway.app API Key : pcscam-entree-nord-2024 // la clé définie à l'étape précédente — elle doit correspondre exactement

Sauvegardez. La caméra redémarre et se connecte à votre réseau WiFi. Elle contacte ensuite PCS en utilisant sa clé API comme identifiant. PCS reconnaît cette clé — qu'il attend depuis l'étape 2 — et associe la caméra physique à l'entrée que vous avez créée dans le tableau de bord.

Pour retrouver votre caméra : dans le dashboard PCS, elle apparaît dans la liste sous le nom que vous lui avez donné à l'étape 2, avec son ID caméra visible dans la page de gestion. Le point vert pulse dès que la connexion est établie.
4

Positionner la caméra & la placer sur la carte

La PCS Cam v1 fonctionne mieux à hauteur de plaque ou légèrement au-dessus, avec un angle qui capte les véhicules de face ou de trois quarts. Évitez le contre-jour direct. Assurez-vous d'avoir du WiFi à l'emplacement choisi. Fixez-la solidement — les vibrations sont l'ennemi juré de la lecture de plaques. Un équipement de cette qualité mérite un montage sérieux, pas deux bandes de scotch.

Une fois la caméra en ligne, ouvrez sa page de gestion dans PCS (icône engrenage depuis le dashboard) et renseignez ses coordonnées GPS. PCS place alors la caméra sur une carte interactive — indispensable dès que vous gérez plusieurs points de surveillance sur un site. Un coup d'œil, et vous savez exactement quelle caméra couvre quelle zone. Pas de devinettes.

Astuce coordonnées GPS : Sur Google Maps, faites un clic droit sur l'emplacement exact de la caméra → "Quelles sont ces coordonnées ?". Copiez-les directement dans PCS.
5

Vérifier le flux en direct

Cliquez sur votre caméra dans le dashboard PCS. Vous devriez voir le flux MJPEG en direct. Si l'image est floue, ajustez la mise au point (petite vis sur l'objectif). Si l'image est noire, la caméra est peut-être dans sa poche. Vérifiez. Ça arrive.

Chapitre 5
05

Configuration finale & Utilisation

Listes, alertes, notifications — le grand final

Votre instance tourne. Vos caméras streament. Roboflow analyse en arrière-plan. Il ne reste plus qu'à dire à PCS exactement ce qui vous intéresse. C'est là que la puissance du système se révèle dans toute sa splendeur.

1

Configurer votre liste de plaques

PCS supporte deux modes radicalement différents dans la section Liste de plaques :

🚫 Liste Noire (défaut)

Les plaques listées déclenchent une alerte. Tout le reste passe sans bruit. Idéal pour surveiller des véhicules spécifiques.

✅ Liste Blanche

Les plaques listées sont autorisées. Toute plaque inconnue déclenche une alerte. Parfait pour un accès contrôlé.

Basculez entre les deux modes via le bouton dans l'en-tête de la section. Ajoutez des plaques, donnez-leur une description parlante ("Client VIP", "Résident Bât. A"), et définissez une priorité si nécessaire.

2

Configurer les notifications

Section Notifications du dashboard. PCS supporte plusieurs canaux :

Telegram

Le plus fiable. Créez un bot via @BotFather, récupérez le token, notez votre Chat ID. Les alertes arrivent instantanément.

Signal

Via CallMeBot. Configurez une fois, notifications chiffrées à vie.

Webhook

Pour les intégrations custom. Tout système qui accepte un POST HTTP peut recevoir vos alertes PCS.

3

Utiliser le tableau de bord au quotidien

L'Historique liste tous les passages détectés — plaque, type de véhicule, couleur, modèle IA utilisé et statut menace. Filtrez par tout, date, type, caméra. Téléchargez les GIFs d'alerte directement depuis le tableau.

La page Caméra (clic sur une caméra) vous donne le flux live, les enregistrements ESP32 (liste + lecture + téléchargement), l'historique des connexions de la caméra, et le cache local d'alertes (500 Mo par caméra, nettoyable en un clic).

Les alertes en temps réel s'affichent sur le dashboard via une bannière rouge — et dans votre appli de messagerie en simultané.

4

Maintenance et nettoyage

Les GIFs d'alerte globaux sont nettoyés automatiquement après 7 jours. Le cache par caméra est limité à 500 Mo — les plus anciens fichiers sont supprimés automatiquement. Vous pouvez forcer le nettoyage depuis la page de chaque caméra. L'historique de détections peut être effacé par caméra depuis la page dédiée. PCS gère son espace. Vous n'avez à vous soucier de rien.
